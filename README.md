# homebrew-tap

```sh
brew install --cask jeong-jae-hun/tap/mindow
brew install --cask jeong-jae-hun/tap/i-db
```

| Cask | App |
|---|---|
| `mindow` | [Mindow](https://github.com/Jeong-Jae-Hun/mindow), a window manager that keeps your Spectacle shortcuts |
| `i-db` | [i-db](https://github.com/Jeong-Jae-Hun/i-db), a database GUI for DataGrip projects (PostgreSQL, Redis, read-only AWS sources); the `db` CLI/TUI installs with `db update` |

Each cask's `sha256` is the value printed in that app's GitHub Release notes.
